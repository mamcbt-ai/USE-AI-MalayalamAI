Cause: Whisper outputs Tamil tokens for Malayalam speech when language="ml" is forced — model confusion between similar scripts
✓ Fix: language=None on transcribe pass (auto-detect) + _fix_ml_script() maps Tamil→Malayalam codepoints
AI
distil-large-v2 returned empty for all Indian languages
Cause: distil-large-v2 is English-only — doesn't support multilingual transcription despite being a Whisper variant
✓ Fix: Reverted immediately. Switched to Groq whisper-large-v3 which is fully multilingual
Infra
Railway watching "main" — ignoring all pushes to "master"
Cause: Railway Source branch set to "main" but entire repo history was on "master" — every deploy was running stale code
✓ Fix: Railway Settings → Source → changed branch from main to master
Encoding
PowerShell Set-Content corrupting Malayalam Unicode files
Cause: PowerShell Set-Content defaults to Windows-1252 encoding. Malayalam characters (U+0D00 range) become ??? or broken sequences, causing Vercel build failures
✓ Fix: All file writes use [System.IO.File]::WriteAllText($path, $content, [System.Text.Encoding]::UTF8)
Bug
UnboundLocalError: lang in event_generator
Cause: line 162 inside event_generator — lang = seg.get("language", "ml") — made Python treat lang as a local variable throughout the entire generator. Line 132 _src_lang = lang failed because lang was local but unassigned at that point
✓ Fix: async def event_generator(lang=lang) — default argument captures the outer lang value at function definition time, avoiding the scoping conflict
Bug
Frontend showed infinite spinner on any backend error
Cause: SSE event handler only processed english_segment, malayalam_segment, complete types. Error events were silently ignored — setIsDone(true) never called
✓ Fix: Added else if (evt.type === 'error') handler — shows error message text and stops spinner
Bug
Free variable 'lang' not associated with value in _run() thread
Cause: Python async function parameter lang not accessible from nested synchronous thread function def _run() in some Python 3.13 closures
✓ Fix: Added _src_lang = lang before def _run(): and used source_lang=_src_lang inside thread
