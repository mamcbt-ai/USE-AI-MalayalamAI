1. Project Overview and History

1.1 Description, Purpose and Target Users

Malayalam Voice AI is a cloud-based speech-to-text SaaS application that converts spoken South Indian language audio into instant English translations. The service addresses a real need: millions of Malayalam, Tamil, Telugu, Kannada, and Hindi speakers who struggle to produce English written content from verbal communication.

Target Users

  • Kerala and South Indian professionals needing quick English documentation from regional language speech
  • Students who think and communicate verbally in their native language
  • Content creators translating regional audio for wider English-speaking audiences
  • Businesses operating across South India requiring multilingual transcription

Supported Input Languages

  • Malayalam (primary)  |  Tamil  |  Telugu  |  Kannada  |  Hindi

Key Features

  • Real-time streaming speech-to-text — results appear word by word as audio is processed
  • Dual output: English translation + native Unicode script (e.g. Malayalam: നമസ്കാരം)
  • 11 translation styles: Standard, Formal, Casual, News, Literary, Business, Academic, Simple, Humorous, Emotional, Bullet Points
  • Subscription plans with enforced daily limits: Free, Basic, Pro, Premium
  • Hallucination detection and filtering — repeated characters and stock phrases auto-removed
  • Works in any mobile or desktop browser — no app download required

4.3 Proxy Architecture — ISP Block Solution

Several Indian ISPs (Airtel, BSNL, Jio home routers) block *.railway.app domains at the DNS level. Solution: Vercel acts as a transparent server-side proxy.

User Browser / Mobile
→
Vercel (vercel.app)
Same domain as frontend
→
Railway Backend
Server-to-server

All API calls use /api/* (relative path on Vercel). Next.js rewrites route them server-side to Railway. User devices never contact Railway directly — ISP blocking is permanently bypassed.

8.4 Scalability Considerations

  • Current: Whisper small on CPU — handles 5-10 concurrent users comfortably
  • High traffic: Upgrade to Railway GPU plan + Whisper medium/large model
  • Database: PostgreSQL managed by Railway — scales with Railway plan
  • Frontend: Vercel CDN scales infinitely — no action needed
  • Rate limiting: 20 req/min per IP — adjust as real traffic grows
